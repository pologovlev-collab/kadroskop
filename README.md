# Кадроскоп

Кроссплатформенное Flutter-приложение для поиска забытых фильмов, сериалов,
аниме, мультфильмов и мультсериалов и ведения большой личной коллекции.

Приложение не является видеоплеером: оно не показывает позицию просмотра и не
предлагает продолжить воспроизведение.

## Реализовано

- адаптивная навигация для телефонов и ПК;
- поиск в TMDB и AniList через собственный backend;
- поиск по неполному названию, реальные популярные произведения и пагинация;
- загрузка и оптимизированное декодирование обложек;
- локальная SQLite-коллекция;
- статусы «в планах», «смотрю», «просмотрено» и «брошено»;
- отметка отдельных эпизодов и всего сериала;
- личные оценки и статистика по времени, типам, жанрам, годам и активности;
- текстовый поиск забытого произведения с проверкой кандидатов в каталогах;
- DeepSeek V4 Flash, альтернативный YandexGPT Lite и обязательный fallback;
- локальный профиль, настройка вкуса, тема и импорт/экспорт коллекции.

В production-интерфейсе нет вымышленных карточек. Тестовые данные можно включить
только в debug-сборке через `KADROSKOP_DEBUG_DEMO_DATA=true`.

## Запуск backend

```powershell
cd backend
dart pub get
Copy-Item .env.example .env
# Откройте backend/.env и заполните нужные серверные ключи
dart run bin/server.dart
```

AniList не требует ключа. Без `TMDB_ACCESS_TOKEN` поиск аниме продолжит работать,
а фильмы и сериалы TMDB будут недоступны.

## Запуск приложения

В другом терминале:

```powershell
flutter pub get
flutter run -d windows
```

Android-эмулятор автоматически обращается к backend по `10.0.2.2:8080`.
Физическому телефону нужен адрес компьютера в локальной сети:

```powershell
flutter run --dart-define=KADROSKOP_API_URL=http://192.168.1.10:8080
```

Для production используйте HTTPS-адрес опубликованного backend.

Windows и Android обращаются к одному процессу backend. После изменения `.env`
сервер необходимо остановить и запустить заново. Если в журнале есть
`SocketException` для `api.themoviedb.org`, это сетевой отказ до проверки ключа:
проверьте брандмауэр/VPN/прокси. При этом backend продолжит отдавать AniList и
покажет предупреждение о недоступном TMDB.

## Проверка

```powershell
flutter analyze
flutter test

cd backend
dart analyze
dart test
```

Данные источников не выгружаются целиком: приложение получает только результаты
поиска и открытые карточки. Это уменьшает нагрузку и соответствует ограничениям
внешних каталогов.
