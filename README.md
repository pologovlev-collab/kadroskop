# Кадроскоп

Кроссплатформенный визуальный прототип приложения для поиска забытых фильмов,
сериалов, аниме и мультфильмов. Одна кодовая база Flutter предназначена для
Android, iOS, Windows, macOS и Linux.

## Что уже работает

- адаптивная навигация: боковая панель на ПК и нижняя панель на телефоне;
- персональная главная, поиск и фильтр по типу;
- интерактивная лента «Помоги вспомнить»;
- карточка произведения и добавление в коллекцию;
- локальная SQLite-база с начальной схемой `media`, `user_media`, `interactions`;
- демонстрационные данные без зависимости от внешнего API.

## Запуск

```powershell
flutter pub get
flutter run -d windows
```

Для Android выберите подключённый эмулятор или устройство через `flutter devices`.
